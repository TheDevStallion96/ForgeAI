# 11. Development Standards & Quality Engineering

## Executive Summary

This document defines the development standards, directory layout rules, coding style guidelines, Git workflows, and testing philosophy for **ForgeAI**.

All contributors—human engineers and autonomous AI agents—must adhere to these standards to maintain codebase consistency and architectural integrity.

---

```

├── Domain/                   # DDD Bounded Context Modules

```

## 🛠️ Code Style & Static Analysis Guidelines

### PHP Guidelines (PHP 8.5)
- **Formatting**: Checked automatically via `Laravel Pint` (`vendor/bin/pint --parallel`).
- **Static Analysis**: Must pass `Larastan` (PHPStan wrapper) at **Level 8** (`vendor/bin/phpstan analyse`).
- **Typing**: Explicit type hints and return declarations on all functions and class methods.
- **Constructor Promotion**: Use PHP 8 constructor property promotion for all DTOs and Services.

### Frontend Guidelines (Vue 3 / TypeScript)
- **Component Style**: Vue 3 Composition API with `<script setup lang="ts">`.
- **Styling**: Tailwind CSS v4 utility classes. Avoid inline style attributes or raw CSS rules.
- **Route Resolutions**: Import typed actions generated by Wayfinder from `@/actions/*`.

## 🧪 Testing Philosophy & Pest v4 Matrix

Every change must be programmatically verified. ForgeAI relies on **Pest v4**:

```php
// Architectural Boundary Assertion (tests/Arch/DomainBoundaryTest.php)
arch('domain modules must remain strictly isolated')
    ->expect('App\Domain\Agent')
    ->not->toUse('App\Domain\KnowledgeVector');

// Feature Test Assertion (tests/Feature/AgentExecutionTest.php)
test('authenticated user can trigger agent execution session', function () {
    Ai::fake(); // Fake LLM responses
    
    $user = User::factory()->create();
    
    $this->actingAs($user)
        ->post(route('agents.sessions.run'), [
            'prompt' => 'Analyze architecture',
        ])
        ->assertStatus(200);
});
```

## 🚀 Quality Check Gate Command

Before opening a PR or tagging a release, run:

```bash
composer run ci:check
```

This single command executes Pint formatting checks, Larastan static analysis, Vue type checks, and the full Pest test suite.
