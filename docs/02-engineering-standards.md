# 02. Comprehensive Engineering Standards

## Executive Summary

This document details the mandatory technical standards for code, documentation, APIs, databases, testing, observability, security, and AI prompt engineering across **ForgeAI**.

Every contribution—whether submitted by human engineers or generated by AI agents—MUST satisfy these standards.

---

## 💻 Backend PHP Standards (PHP 8.5)

1. **Formatting**: Formatted automatically via **Laravel Pint** (`vendor/bin/pint --parallel`).
2. **Static Analysis**: Must pass **Larastan** (PHPStan wrapper) at **Level 8** (`vendor/bin/phpstan analyse`).
3. **Strict Typing**: `declare(strict_types=1);` MUST be enabled on every PHP file. All parameters and returns require explicit type hints.
4. **Control Structures**: Always use curly braces for control structures, even for single-line bodies.
5. **Constructor Promotion**: Use PHP 8 constructor property promotion for all DTOs, Services, and Actions:
   ```php
   public function __construct(
       public readonly GitHubClient $github,
       public readonly AgentRepository $agents,
   ) {}
   ```

---

## 🎨 Frontend & Styling Standards (Vue 3 / Inertia v3 / Tailwind v4)

1. **Script Setup**: Vue 3 components MUST use Composition API with `<script setup lang="ts">`.
2. **Single Root Element**: All Vue components must have a single root DOM element.
3. **Route Resolution**: NEVER hardcode URL strings. ALWAYS import typed controller/route actions generated by `@laravel/vite-plugin-wayfinder` from `@/actions/*`.
4. **Tailwind CSS v4**: Use utility classes exclusively. Avoid inline CSS style attributes or custom CSS files outside `resources/css/app.css`.

---

## 🗄️ Database & Schema Standards (PostgreSQL 16 + `pgvector`)

1. **Primary Keys**: All tables MUST use UUID primary keys (`id UUID PRIMARY KEY DEFAULT gen_random_uuid()`).
2. **Multi-Tenant Isolation**: All tenant-owned tables MUST include an `organization_id` foreign key mapped to `organizations(id)` and implement a global Eloquent tenant scope.
3. **Vector Indexes**: All vector columns (`vector(1536)`) MUST define HNSW cosine distance indexes (`USING hnsw (embedding vector_cosine_ops)`).
4. **Immutable Ledgers**: Financial and audit tables (`token_ledgers`, `audit_logs`) MUST be append-only with database-level triggers blocking UPDATE and DELETE statements.

---

## 🧪 Testing Standards (Pest v4)

1. **Framework**: All tests MUST be written in **Pest v4** (`php artisan make:test --pest`).
2. **Test Pyramid**:
   - **Architectural Tests (`tests/Arch/`)**: Verify layer encapsulation and module isolation.
   - **Unit Tests (`tests/Unit/`)**: Test domain aggregates, DTOs, and utility services.
   - **Feature Tests (`tests/Feature/`)**: Test Inertia controller actions, auth policies, and API endpoints.
   - **Eval Tests (`tests/Evals/`)**: Evaluate LLM prompt responses and tool invocation accuracy.
3. **Mocking**: Use `Ai::fake()` for AI driver assertions to avoid executing live LLM API calls in CI pipelines.

---

## 🤖 AI Prompt Standards

1. **Prompt Isolation**: System instructions MUST be isolated from untrusted user content using XML/delimiter framing (`<user_prompt>...</user_prompt>`).
2. **Version Control**: All system prompts MUST be stored as version-controlled Markdown files inside `.prompts/` with YAML frontmatter specifying model parameters, temperature, and tool bindings.
3. **Output Validation**: Prompts requesting structured output MUST enforce strict JSON Schemas validated via `laravel/ai`.
